# StackPicker Privacy Policy

_Last updated: 21 August 2026_

StackPicker does not collect, store, transmit or sell any data. There is no
account, no server, no analytics and no tracking of any kind.

## What the extension does

When you click the StackPicker toolbar icon, it examines the page you are
currently viewing in order to identify the technologies it is built with. It
reads:

- the page's HTML markup, `<meta>` tags and cookies set by that page
- the URLs of scripts and stylesheets the page loads
- JavaScript variables the page defines (for example `window.React`)
- the HTTP response headers of the page's own address, retrieved with a `HEAD`
  request to that same site

These are compared against a fingerprint database that ships inside the
extension. The result is shown in the popup.

## What happens to that information

Nothing leaves your browser. The analysis runs entirely on your machine, the
result exists only for as long as the popup is open, and nothing is written to
disk or to any storage area. StackPicker has no backend to send data to.

## When it runs

Only when you click the extension icon. StackPicker does not run in the
background, does not observe your browsing, and does not act on pages you have
not explicitly asked it about.

## Permissions

- **`activeTab`** — gives StackPicker temporary access to the tab you are
  viewing, and only when you click its toolbar icon. It requests no standing
  access to any website.
- **`scripting`** — used to run the detection routine inside the current page,
  which is required to see JavaScript variables that identify a framework.

## Third parties

None. StackPicker contains no third-party analytics, advertising, or tracking
code, and loads no remote code at runtime.

## Children

StackPicker is a developer tool that collects no data from anyone, including
children.
